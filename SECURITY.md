# Security policy

Fixes target the latest plugin versions on the default branch. Report suspected
vulnerabilities through this repository's **Security → Report a vulnerability**
when private reporting is enabled. Otherwise, contact the repository owner
through a private channel before disclosing details publicly.

Include the affected plugin and version, reproduction steps, and impact. Redact
credentials and personal data. Plugin contributors should document external
services, required permissions, and executable hooks in the plugin README.
