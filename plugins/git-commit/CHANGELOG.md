# Changelog

## [1.1.0] - 2026-10-21

- Show prominent warnings for confirmed or potential breaking changes, with staged
  evidence, affected consumers, and required adaptation.
- Wait for explicit approval of the breaking impact before committing or changing
  the index; allow the user to proceed, revise, or split the change.
- Include breaking-change warnings in draft previews without requesting a commit.
- Mark confirmed breaking commits with `!` and a `BREAKING CHANGE:` footer.

## [1.0.0] - 2026-10-06

- Package the staged-only Conventional Commit workflow for Codex and Claude Code.
